# Flask → FastAPI Migration Plan

## Overview
Migrate IntroChat from Flask + Flask-SocketIO to FastAPI with native WebSockets. No new features, no database changes, no frontend redesign.

---

## Grill Outcomes (All Dimensions Resolved)

| Dimension | Decision |
|-----------|----------|
| WebSocket approach | Native FastAPI WebSockets (replace socket.io JS client) |
| Async vs sync | All `async def` handlers |
| Template url_for | Starlette syntax, fallback to hardcoded `/static/...` if needed |
| Edge case: disconnect mid-match | Accept — match available via HTTP API |
| Edge case: multi-tab user | Last-connection-wins |
| Edge case: QR URL | Derive dynamically from `request.base_url` |
| Alternative: DB driver | `aiosqlite` — proper async, all DB calls `await` |
| Alternative: request validation | Pydantic models (`app/schemas.py`) |
| Dependency: message protocol | Locked (see below) |
| Risk: url_for syntax | Verify in Batch 1, fallback to hardcoded |
| Risk: async DB init | `@app.on_event("startup")` |
| Risk: DB path duplication | Centralize in `app/config.py` |

---

## Message Protocol (Frontend ↔ Backend)

### Server → Client
```json
{"type": "match_found", "match_id": "...", "room_id": "...", "user1_username": "...", "user2_username": "..."}
{"type": "connection_exchanged", "user1_username": "...", "user2_username": "..."}
{"type": "connection_declined"}
```

### Client → Server
```json
{"type": "hello", "user_id": "...", "room_id": "..."}
{"type": "join_room", "room_id": "..."}
```

## Batches (Ordered by Dependency)

### Batch 1: Dependencies & App Bootstrap
**Files:** `requirements.txt`, `app/__init__.py`, `app/__main__.py`, `app/schemas.py`, `app/config.py`

- `requirements.txt`: Remove `Flask`, `Flask-SocketIO`, `eventlet`. Add `fastapi`, `uvicorn[standard]`, `websockets`, `jinja2`, `aiosqlite`, `python-multipart`
- `app/config.py`: Centralize `DB_PATH`, `HOST`, `PORT` constants (QR URL derived dynamically at runtime)
- `app/schemas.py`: Define Pydantic models
- `app/__init__.py`: Rewrite — `FastAPI()` app, `StaticFiles` mount at `/static`, `Jinja2Templates`, startup event for async `init_db()`, register routes, start cleanup thread
- `app/__main__.py`: `uvicorn.run("app:app", host="0.0.0.0", port=5000, reload=True)`
- **Verify:** `python -c "from app import app; print(app)"`

### Batch 2: Async Database Layer
**Files:** `app/database.py`

- Replace `sqlite3` with `aiosqlite`, all calls `await`
- Keep same schema
- **Verify:** `python tests/test_db.py`

### Batch 3: WebSocket Connection Manager (New File)
**Files:** `app/connection_manager.py`

- `ConnectionManager` class with connect/disconnect/send/broadcast
- Singleton `manager` instance

### Batch 4: HTTP Routes Migration
**Files:** `app/routes.py`

- `@router.get/post` decorators, `async def`, Pydantic bodies
- Path params: `<id>` → `{id}`
- `templates.TemplateResponse(...)`
- QR URL from `request.base_url`
- **Verify:** `python -c "from app.routes import router"`

### Batch 5: WebSocket Endpoint
**Files:** `app/routes.py`

- `@router.websocket("/ws")`
- Hello message → register, loop → handle join_room, disconnect → unregister

### Batch 6: Matchmaking + Route Emit Updates
**Files:** `app/matchmaking.py`, `app/routes.py`

- `find_match`/`create_match` → `async def`
- `socketio.emit` → `manager.broadcast_to_users`
- **Verify:** `python tests/test_app.py`

### Batch 7: Frontend WebSocket Migration
**Files:** `app/static/js/utils.js`, `room.js`, `chat.js`

- `initSocket(userId, roomId)` returns native WebSocket wrapper
- onmessage dispatcher replaces `.on('event', ...)`
- `.send(JSON.stringify({type, ...}))` replaces `.emit(...)`

### Batch 8: HTML Template Updates
**Files:** `app/templates/*.html` (4 files)

- `url_for` → Starlette syntax or hardcoded `/static/...`
- Remove socket.io CDN script

### Batch 9: Test Suite Update
**Files:** `tests/test_app.py`

- `TestClient(app)` from `httpx`
- Remove Flask/SocketIO import checks
- **Verify:** `python tests/test_app.py` → all pass
