# PLAN_2026_05_28_001

## Problem Statement

IntroChat's current UI has no design system — a single 795-line `global.css` with hardcoded colors, inconsistent inline styles in UserInfoPage, no transitions between page states, and no design tokens. The visual identity (purple gradient background, blue/green buttons) doesn't match the "calm, cozy, minimal" product ethos for introverts.

## Goals & Non-Goals

### Goals
- Establish a **Calm × Cozy × Minimal** design system with design tokens
- Install **shadcn/ui** as the component foundation (Tailwind CSS + Radix primitives)
- Restructure all 4 pages + 6 components to use shadcn primitives + Tailwind
- Convert all imports to `@/*` path alias for consistency
- Remove all inline styles from pages
- Apply warm neutral palette, Sora font, generous spacing, minimal fade motion

### Non-Goals
- No new pages or features
- No backend changes
- No comprehensive accessibility audit (structural HTML may change but ARIA isn't in scope)
- No E2E test updates (unless selectors break from class name changes)
- No dark mode (unless explicitly requested later)

## Technical Approach

Two-phase workflow as defined in AGENTS.md UI/UX section:

**Phase 1 — Setup & Design Tokens:**
1. Install Tailwind CSS v3 + PostCSS + autoprefixer
2. Run `npx shadcn@latest init --defaults` for config scaffolding
3. Add 5 shadcn components: `button`, `card`, `input`, `label`, `select`
4. Define design tokens in `tailwind.config.js`: warm neutral palette, Sora font family, spacing scale, fade timing
5. Update `global.css` to Tailwind directives + CSS variable layer

**Phase 2 — Restructure:**
6. Rewrite 6 components (Timer, PersonCard, PromptCard, MatchCountdown, ConnectionCard, QRDisplay) to use shadcn primitives + Tailwind
7. Rewrite 4 pages (HomePage, UserInfoPage, RoomPage, ChatPage) to use shadcn + Tailwind; strip inline styles
8. Convert all relative imports to `@/*` alias across source + test files

### Architecture & Design Decisions

**Design System Tokens (in `tailwind.config.js`):**
- Colors: warm neutral palette (cream `#FDFBF7` bg, warm taupe `#8B7E74` accents, sage `#8BA888` affirmatives)
- Font: Sora (single rounded sans, warm geometric)
- Container: max-width 660px, centered
- Card padding: 32-40px
- Border radius: 16px cards, 12px inputs/buttons
- Motion: 0.4s ease-out fade transitions
- Shadows: soft `0 4px 20px rgba(0,0,0,0.06)`

**Minimal shadcn:** Only `button`, `card`, `input`, `label`, `select` — maps 1:1 to current UI primitives. Custom display components (Timer, PersonCard, etc.) use shadcn's `Card` composition + Tailwind for custom visuals.

**shadcn init:** `--defaults` flag for deterministic setup, then override tokens. This keeps future installs clean (`npx shadcn add <name>`).

**Import consistency:** All source + test files use `@/*` path alias. No mixed relative/alias imports.

## Grill Outcomes

### Dimension: Assumptions
- Decision: Minimal shadcn — only `button`, `card`, `input`, `label`, `select`
- Rationale: Shadcn owns component structure/composition; custom components (Timer, PersonCard, etc.) are unique visual constructs better served by naked Tailwind + design tokens
- Impact: Smaller dependency footprint, no unnecessary Radix primitives

### Dimension: Edge cases
- Decision: `npx shadcn@latest init --defaults` then override configs with design tokens
- Rationale: Deterministic, modular, future components addable via `npx shadcn add`

### Dimension: Dependencies
- Decision: Install standard shadcn stack — tailwindcss@3, postcss, autoprefixer, @radix-ui/react-select/slot/label, cva, tailwind-merge, clsx, lucide-react
- Rationale: Standard shadcn pipeline, Vite auto-detects PostCSS

### Dimension: Risks
- Decision: No test breakage expected — tests check behavior not CSS class names. TypeScript strict mode compatible with shadcn output
- Impact: Low risk

### Dimension: Consistency
- Decision: Convert ALL source + test file imports to `@/` alias (consistent with shadcn style)
- Impact: Touches ~20 files but establishes consistency

### Dimension: Code Discovery
- Decision: Nothing missed by the plan. Community 11 (Frontend Modules) covers all 26 affected files
