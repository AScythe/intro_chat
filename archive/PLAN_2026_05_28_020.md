Add two new agent skills (`frontend-design` and `shadcn`) for structured frontend UI/UX work, and document their sequential usage pattern in AGENTS.md.

3. Plan document passes all 8 readiness gates

## Technical Approach

Two skills used sequentially for frontend work:
- **Phase 1 (Design):** `frontend-design` — produces a design spec (aesthetic direction, color system, typography, motion, layout)
- **Phase 2 (Implementation):** `shadcn` — implements components following the design spec

Conflict resolution: design spec owns visual decisions; shadcn owns composition/accessibility.

The `shadcn` skill uses a hybrid approach: embed ~80 lines of essential rules and patterns inline, reference `skills.sh` for deep edge cases.

### Architecture & Design Decisions

- **Skill type:** Both use `type: subskill` (matching existing non-workflow skills)
- **frontend-design boundary:** Pure design spec — no code output. Trivial mechanical changes may bypass this step.
- **shadcn content strategy:** Hybrid — embed essential rules + component selection table + conflict rules; reference upstream for full rulebook
- **Conflict resolution:** Design spec wins for color/typography/spacing/motion/aesthetics; shadcn wins for component selection/imports/composition/accessibility
- **Placement in AGENTS.md:** After "SDD Workflow — Phase Order" section
