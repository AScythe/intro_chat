# PLAN_2026_05_29_001

## Problem Statement

IntroChat's frontend has a functional but unpolished UI. It lacks:
- A cohesive, memorable visual identity that reflects the app's introvert-friendly soul
- SaaS-standard interaction patterns (loading skeletons, empty states, toasts, page transitions)
- Dark mode support
- Mobile responsiveness
- Consistent spacing, typography, and visual hierarchy across all pages

The goal is a full visual redesign: SaaS structure and interaction polish + warm, safe, introvert-friendly aesthetic.

## Goals & Non-Goals

### Goals
- Design spec defining new visual identity (colors, typography, spacing, motion, layout)
- New CSS variable design tokens + Tailwind config (light + dark mode)
- Smooth route-level page transitions (fade/slide)
- Progress indicator across user flow (Join → Profile → Room → Chat)
- Loading skeletons, empty states, error toasts on every page
- All 4 pages redesigned with new layouts (HomePage, UserInfoPage, RoomPage, ChatPage)
- All 6 sub-components redesigned alongside their parent pages
- Mobile responsiveness pass
- All 81 existing tests updated to pass; 0 regressions

### Non-Goals
- Backend changes
- New features or API endpoints
- React Router version upgrade or routing overhaul
- Full a11y audit (beyond what shadcn provides)

## Success Metrics

1. Design spec complete with all sections + token mapping table
2. All CSS variables and Tailwind tokens match the spec exactly
3. `motion` installed and working; route transitions smooth
4. Each page has loading, empty, error, and success states
5. Progress indicator guides user through Join → Profile → Room → Chat
6. All pages polished at desktop and mobile widths
7. Dark mode toggle works (or auto-detects) with no contrast issues
8. All 81 frontend tests pass
9. `npx tsc --noEmit` passes — no type errors
10. `npm run build` succeeds

## Technical Approach

**Two-skill workflow:** `frontend-design` produces a spec → `shadcn` implements it.

The redesign follows a warm SaaS direction: polished interaction patterns (structure/flow) combined with a gentle, safe visual soul (feel/looks). The app's purpose — helping introverts connect at events — drives the aesthetic.

Dark mode palette is defined in Phase 2 alongside light mode to avoid retrofitting later. Sub-components are redesigned in the same batch as their parent page to keep each deliverable self-contained.

### Architecture & Design Decisions

- **Page transitions:** `motion` library with `AnimatePresence` wrapping `<Routes>`. Fade/slide variants.
- **Progress indicator:** Fixed top bar or step indicator in App.tsx, reading current route to highlight active step.
- **Toasts:** `sonner` (already available via shadcn). One-time setup in App.tsx, then call `toast()` from any page.
- **Skeletons:** `Skeleton` component from shadcn (already available). Per-page loading states.
- **Dark mode:** CSS variables in `global.css` under `.dark` / `prefers-color-scheme`. Toggle stored in localStorage.
- **Sub-components:** Redesigned in the same batch as their parent page (e.g., QRDisplay with HomePage, PersonCard + MatchCountdown with RoomPage).
- **Tests:** Updated alongside page/component changes in the same batch.
