# PLAN_2026_05_20_015

## Requirements / Problem Statement

Integrate **cocoindex-code** (semantic code search via Tree-sitter + embeddings) and **ast-grep** (structural code search/rewrite via AST patterns) into the existing SDD workflow. Currently, all code finding uses `grep`/`glob` and all code rewriting uses string-based `edit` — both fragile against whitespace/comment variations and incapable of semantic understanding.

The pipeline: **cocoindex-code finds the right code block semantically → ast-grep rewrites it surgically at the AST level**.

## Solution

Three-layer integration:

1. **Plugin layer** — Install `opencode-ast-grep` npm plugin exposing `ast_grep_search` and `ast_grep_replace` tools to the agent
2. **MCP layer** — Install `cocoindex-code[full]` as an MCP server (`ccc mcp`) providing semantic code search
3. **Skill layer** — Update 6 existing SDD skills (+ AGENTS.md) to use these tools, prefer them over grep/edit where appropriate

### Approach & Design Decisions

- **opencode-ast-grep** chosen over manual `@ast-grep/cli` npm install because it wraps sg binary discovery/download + tool registration into one package
- **cocoindex-code[full]** chosen over slim variant for zero-config local embeddings (no API key needed)
- Smart Tools sections are inserted into existing skill structures, never replacing core methodology — always additive
- `implement-plan` gets the largest addition since it's the primary writing phase where ast-grep replace shines

## Grill Outcomes

### Dimension: Assumptions
- Decision: opencode-ast-grep plugin assumed compatible with @opencode-ai/plugin v1.14.48
- Rationale: Plugin system is stable; fix-forward on any issues
- Impact: No verification step needed before install

### Dimension: Alternatives
- Decision: cocoindex-code [full] with local embeddings
- Rationale: Most mature (1.6k stars), Tree-sitter AST chunking complements ast-grep's AST rewriting perfectly
- Impact: ~1GB one-time install via `uv tool install`

### Dimension: Dependencies
- Decision: uv available (0.5.3) — use `uv tool install 'cocoindex-code[full]'`
- Decision: opencode-ast-grep npm plugin auto-downloads sg binary — no separate sg install needed
- Impact: Verify cocoindex install with quick `ccc init --demo` after installation

### Dimension: Risks
- Decision: Windows compatibility confirmed for both tools (opencode-ast-grep maps win32-x64 to MSVC binary, cocoindex-code is pure Python)
- Decision: Accept the ~1GB torch dependency risk; slim variant is fallback
- Impact: No special handling needed

### Dimension: Edge Cases
- Decision: No edge cases beyond standard install failure handling
- Decision: If `ccc init --demo` fails, report and offer slim variant or manual API key config
- Impact: Verification step catches failures early

### Dimension: Consistency
- Decision: Smart Tools sections follow existing skill structure conventions (same format, same placement patterns)
- Decision: Only additive — no behavioral changes to existing workflow
- Impact: Zero risk of workflow disruption
