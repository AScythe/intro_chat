# PLAN_2026_05_15_013

## Requirements / Problem

Switch Python tooling from `python`/`pip` to `uv` (Astral's fast Python package/project manager). Remove `requirements.txt` in favor of pyproject.toml dependency declarations, update all command invocations across docs, configs, skills, and source code to use `uv run` prefix.

## Solution

Three-layer migration:

1. **Core config**: Move 8 dependencies from `requirements.txt` into `pyproject.toml` as `[project.dependencies]`, delete `requirements.txt`, run `uv sync` to generate `.venv/` + `uv.lock`
2. **Command updates**: Replace all `python ...` invocations with `uv run python ...` and all `pip install ...` with `uv sync` across docs, skills, configs, and source code
3. **Documentation**: Update README.md prerequisites and setup steps for uv

### Approach & Design Decisions

- **Dependencies → pyproject.toml**: uv reads `[project.dependencies]` natively. This is the canonical uv workflow (PEP 621).
- **`uv run python -m app` not `uv run app`**: No `[project.scripts]` entrypoint — keep invocation explicit, avoids added scope.
- **`uv run pytest` not `python -m pytest`**: `uv run` resolves the tool from `.venv/` directly; no `-m` needed for installed commands.
- **Plan files untouched**: Historical artifacts, read-only per AGENTS.md policy.
- **Shebangs kept**: `#!/usr/bin/env python3` in test files still works for direct Unix execution outside uv.

### Edge Cases

- **uv not installed**: Add standalone installer to README.md prerequisites. User confirmed Option B (standalone).
- **`.venv/` not created yet**: `uv run` auto-discovers `.venv/` in parent directories. If missing, falls back to system Python. Setup steps ensure `uv venv` + `uv sync` run first.
- **Playwright webServer subprocess**: `uv run` from `cwd: ..` (project root) — finds `.venv/` at root. `uv` on PATH required.
- **Old `venv/` vs new `.venv/`**: uv defaults to `.venv/` (with dot). Both patterns already in `.gitignore`. No existing venv dirs on this system.
- **`uv.lock` git tracking**: No `*.lock` pattern in `.gitignore`. File will be tracked normally.
