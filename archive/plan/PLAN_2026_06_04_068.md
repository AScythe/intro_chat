# PLAN_2026_06_04_068

## Problem Statement

`update-docs` was restructured into dual-mode (explicit/implicit) under PLAN_2026_06_03_067, but the 6 sub-skills it delegates to (`update-architecture-md`, `update-agents-md`, `update-readme-md`, `update-specifications-md`, `update-best-practices-md`, `update-agent-setup-md`) have zero awareness of implicit mode. Their Investigation Protocols say "compare against the full codebase — not against previous session changes", which directly contradicts implicit mode's "delta only" behavior. When `update-docs` (implicit) calls a sub-agent with `mode="implicit"`, the sub-agent loads the sub-skill and sees conflicting instructions — full codebase walk vs. delta scan.

## Goals & Non-Goals

### Goals
- Each sub-skill gets a lightweight "Invocation Modes" section describing explicit vs implicit behavior
- The implicit mode override explicitly supersedes the full Investigation Protocol
- Phase 0 in each sub-skill includes mode determination
- Instructions are consistent across all 6 files — no contradictions with each other or with `update-docs`
- All tests pass after changes

### Non-Goals
- No full dual-mode restructure per sub-skill (Purpose table, etc.) — too heavy
- No changes to `update-docs` SKILL.md or `review-implementation` SKILL.md
- No changes to code files — SKILL.md only

## Success Metrics

- Implicit mode section explicitly overrides: "The full Investigation Protocol below is replaced by a delta scan"

- Investigation Protocol header is prefixed: "**Explicit mode only.** For implicit mode see Invocation Modes above."

## Technical Approach

### Invocation Modes template (same text, inserted after Audience section in each sub-skill)

> ## Invocation Modes
>
> This skill supports two invocation modes. **Explicit** (default, standalone): follows the full Investigation Protocol below. **Implicit** (invoked by `update-docs` Phase 3): investigation is scoped to diff files from the caller. In implicit mode the full Investigation Protocol below is replaced by a delta scan — only analyze changed files against the current document. Graphify context is provided by `update-docs`; skip the Phase 0 graphify query.

### Phase 0 addition (append to existing Phase 0 checklist in each sub-skill)

> - [ ] Determine invocation mode — if implicit, skip full codebase walk and accept scope from caller (diff context)

### Investigation Protocol prefix (add before the existing "Investigation Protocol:" block in each sub-skill)

> **Explicit mode only.** For implicit mode see Invocation Modes above.

### Contradiction prevention
- The "Explicit mode only" prefix is a guardrail — when mode=implicit, the sub-agent knows to skip the protocol below
- The Invocation Modes section is the authority for implicit behavior
- `update-docs` implicit path already says "sub-agents skip full codebase walk" — the sub-skills now say the same thing, creating a consistent chain

### Architecture & Design Decisions
- **Self-contained consistency:** Each sub-skill is loaded independently by a sub-agent. The Invocation Modes section is self-contained per file, not cross-referenced.
- **Template text, not custom:** Same Invocation Modes text across all 6 files prevents drift. Only the file-specific heading IDs differ in the Protocol prefix link.
- **Override, not supplement:** The implicit mode instruction explicitly supersedes the full protocol, not adds to it. No ambiguity about which instructions take precedence.
