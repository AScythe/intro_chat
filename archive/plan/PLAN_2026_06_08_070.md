## Problem Statement

DOCUMENTATION_SCOPE_GUIDE.md analysis revealed gaps between its document boundary rules and the current state of the 6 per-doc update skills + the update-docs orchestrator:

- "What NOT to Include" tables in all 6 per-doc skills are missing AGENT_SETUP.md and DESIGN_SPEC.md as routable destinations
- DOCUMENT_GUIDELINES.md treats DEMO_GUIDE.md as active, but it was archived to `archive/DEMO_GUIDE.md`
- update-docs Doc Sync Triggers table is missing DESIGN_SPEC.md
- update-readme-md lacks a boundary rule for agent-vs-project setup (update-agent-setup-md already has one)

## Goals & Non-Goals

### Goals

- Add AGENT_SETUP.md and DESIGN_SPEC.md rows to all 6 per-doc skills' "What NOT to Include" tables
- Update DOCUMENT_GUIDELINES.md to reflect DEMO_GUIDE.md archived status (move §4 to appendix, remove from Quick Reference Table and §8 Doc Sync Steps)
- Add DESIGN_SPEC.md trigger row to update-docs Doc Sync Triggers table
- Add AGENT_SETUP boundary rule to update-readme-md Content Rules (following update-agent-setup-md's style)

### Non-Goals

- NOT creating new skills (update-design-spec-md, update-demo-guide-md)
- NOT changing per-category granularity of the Doc Sync Triggers table
- NOT modifying source code or non-documentation files
