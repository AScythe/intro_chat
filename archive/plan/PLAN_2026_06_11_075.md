# PLAN_2026_06_11_074

## Problem Statement

`review-implementation` currently runs `update-docs` (implicit) in Phase 5 — *after* all verification, session save, and sign-off. This means:

1. Docs are synced *after* tests already passed — if doc changes break structural tests (`test_agent_guidelines.py`), the test failure is discovered too late (post sign-off).
2. `rebuild-test-and-indexes` runs its delta sync, tests, triage, and index rebuild all sequentially — missing parallelism opportunities.

## Goals

- Move `update-docs` (implicit) to Phase 0, *before* `rebuild-test-and-indexes`, so docs are in sync before tests run.
- Make both Phase 0 steps fully automatic (no user interaction gates).
- Add parallelism to `rebuild-test-and-indexes` (implicit) where appropriate.
- Decompose `review-implementation` Phase 5 from doc editing into read-only cross-reference verification.

## Non-Goals

- No changes to explicit modes (standalone invocation) of either skill.
- No changes to Phase 1-4 of `review-implementation`.
- No changes to the sub-agent-based explicit path of `update-docs`.

## Detailed Changes

### 1. `update-docs/SKILL.md` — Replace Implicit Path (lines 126–203)

**Old:** 5 phases (Scope → Propose via sub-agents → Quick Approval [user gate] → Apply → Verify with cross-ref check)

**New:** 4 steps, no user interaction, no cross-ref verification.

#### New implicit path structure:

```
## Implicit Path (Phase 0a of review-implementation)

**Detection method:** git diff delta.
**Trust boundary:** Caller ran baseline tests before invoking. Doc deltas are derived from the same git diff the implementer already tested — auto-apply is safe.

### Step 1: Detect Changed Files

git diff --name-only $(git merge-base HEAD main) HEAD

### Step 2: Match Against Doc Sync Triggers

Same trigger table as explicit mode.

### Step 3: Propose and Apply (Parallel Sub-Agents, Sequential Apply)

For each triggered doc, launch a Task sub-agent (read-only, returns proposals).
Collect all proposals. Main agent applies edits sequentially via `edit` tool.
No Quick Approval gate.

### Step 4: Report

| Scenario | Output |
|----------|--------|
| N docs updated | "Implicit doc sync complete. [N] doc(s) updated: [list]." |
| No triggers matched | "Implicit doc sync complete. No doc updates needed." |
| Sub-agent or edit failure | "WARNING: [detail]. Non-blocking." |
```

**Removed from old implicit path:**
- Phase 3 (Quick Approval) — entire section removed
- Phase 5 (Cross-Reference Audit) — entire section removed (moves to review-implementation Phase 5)

**`## Hand-off` section** — update to match new 4-step structure.

**Exit Declaration:**
```
- **Implicit mode:** State clearly: "**Implicit doc sync complete. [N] doc(s) updated.**" (or "No doc updates needed.")
```

**Next Step:**
```
- **Implicit mode:** Control returns to `review-implementation` Phase 0 (proceeds to rebuild-test-and-indexes).
```

- [ ] No orphaned sections — every section in each doc is reachable from another doc or from the doc's own TOC
