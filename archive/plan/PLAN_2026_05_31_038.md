# PLAN_2026_05_31_001

## Problem Statement

The intro_chat codebase has accumulated code-quality and architecture gaps across 6 areas: module boundaries (WebSocket inline in routes.py), type safety (old-style typing, bare dict defaults), DRY violations (BASE_DIR computed twice), missing logging infrastructure (P0 convention gap), and stale documentation.

## Goals & Non-Goals

### Goals
- Improve module boundaries by extracting WebSocket handler from routes.py
- Modernize type annotations (Dict/Set → builtins)
- Fix bare dict defaults for TypedDict access
- Eliminate BASE_DIR duplication
- Add logging infrastructure per AGENTS.md requirements
- Update ARCHITECTURE.md to match current code

### Non-Goals
- No behavior changes, bug fixes, or new features
- No restructuring of frontend code
- No database schema changes

## Success Metrics
- All existing tests pass (31 backend, 96 frontend) + TSC clean
- Zero new LSP type errors in modified files
- ARCHITECTURE.md `state.py` descriptions match actual TypedDicts
- Every Python file has `import logging` + `logger = logging.getLogger(__name__)`

## Technical Approach

Apply changes in 6 sequential batches, each independently testable. Each batch touches a small set of files with no cross-batch dependencies.

### Batch 1: Extract WebSocket handler
- New file: `app/websocket_handler.py` — contains `websocket_endpoint` function
- Modified: `app/routes.py` — remove WS handler, add import + delegate to new module
- Modified: `app/__init__.py` — no change needed (router stays in routes.py)
- Test: all WS tests reroute through new module

### Batch 2: Modernize typing
- Modified: `app/connection_manager.py` — `Dict → dict`, `Set → set`
- No test changes needed (runtime identical)

### Batch 3: Fix bare dict defaults
- Modified: `app/routes.py` lines 132-133, 151-152
- `active_users.get(match['user1_id'], {})` → `active_users.get(match['user1_id']) or {}`
- No test changes needed

### Batch 4: DRY BASE_DIR + unused imports
- Modified: `app/config.py` — keep BASE_DIR (already there)
- Modified: `app/__init__.py` — import BASE_DIR from config instead of recomputing
- Modified: `app/routes.py` — remove unused `Any` import
- No test changes needed

### Batch 5: Logging infrastructure
- Modified: All 12 `app/*.py` files — add standard logging block
- Modified: `app/routes.py:61` — replace `print()` with `logger.error(c)` with `exc_info=True`
- Test: all tests pass (logging is additive)

### Batch 6: Stale docs
- Modified: `docs/ARCHITECTURE.md` lines 177-179 — update state.py descriptions
- No test changes needed
