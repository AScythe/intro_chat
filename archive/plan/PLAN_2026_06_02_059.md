# PLAN_2026_06_02_049

## Problem Statement

After implementing the event organization feature, the codebase accumulated several quality and structural debt items: duplicate logging configuration, missing test coverage, mixed-concern files, type safety gaps, shared mutable state without synchronization, and stale documentation. These don't affect behavior but hinder maintainability.

## Goals & Non-Goals

### Goals
- Consolidate duplicate `logging.basicConfig()` into one place
- Remove dead/unused code (duplicate types, unused re-exports)
- Add missing `// Description:` headers to new shadcn/ui files
- Fix referential transparency violations (GET endpoints that write)
- Extract repeated DB queries into shared helpers
- Add missing test coverage for the new `OrganizeEventPage` and other gaps
- Rename misleading function names
- Fix minor type safety and immutability issues
- Split `routes.py` by concern (HTML / API / WS)
- Encapsulate shared mutable state in `state.py` behind accessor class

### Non-Goals
- No behavior changes, bug fixes, or new features
- No API contract changes
- No database schema changes
- No dependency updates
- No documentation sync (deferred to `update-docs` phase)

## Success Metrics

1. All backend tests pass with same count
2. All frontend tests pass with same or increased count
3. All structural validation tests pass
4. TypeScript `tsc --noEmit` passes
5. `npm run build` passes
6. No behavioral regressions
