# PLAN_2026_06_03_066

## Problem Statement

The `rebuild-indexes` skill currently only rebuilds CocoIndex and Graphify indexes. It does not verify that tests pass before rebuilding, and it does not update stale test references. When run in explicit mode (standalone "rebuild indexes"), the caller has no guarantee that the codebase is in a valid state before indexes are rebuilt. Additionally, the skill has not received the structural consistency pass (Purpose annotations, numbered Steps, clean exit/next-step declarations) that 6 other skills have recently been updated with.

## Goals & Non-Goals

### Goals
- Rename skill from `rebuild-indexes` to `rebuild-test-and-indexes`
- In explicit mode: full direct codebase scan (no git diff) → fix all stale/outdated/broken test refs → run full test suite → triage (max 3 cycles) → rebuild indexes
- In implicit mode: git diff delta → update only structural refs for changed files → run full test suite → conditional rebuild
- Apply structural consistency (Purpose annotations, Steps, exit declarations) matching the pattern from 6 recently-updated skills
- Update all cross-references (10 across 6 files) to the new skill name

### Non-Goals
- No source code modifications (test files only)
- No change to how indexes are built (CocoIndex/Graphify commands unchanged)
- No addition/removal of skills — rename only

## Success Metrics

1. Skill directory renamed; all cross-references updated
2. All tests pass after structural sync + stale-fix iteration (max 3 cycles)
3. Indexes rebuild successfully after tests pass
4. `test_agent_guidelines.py` routing test cases pass for new skill name
5. All baseline tests still pass

## Technical Approach

### Skill Restructure

The `rebuild-test-and-indexes` skill will have two invocation modes with fundamentally different detection strategies:

**Explicit mode** (user says "rebuild test and indexes"): Full direct codebase scan — **no git diff**. Scans test files against the current filesystem to find ALL stale/outdated/broken references:
1. **Full codebase audit** — scan every test file's hardcoded paths, skill names, imports against current filesystem; fix mismatches; check all imports resolve
2. **Run all test suites** — backend, agent guidelines, frontend
3. **Triage & iterate** — apply Failure Triage table (max 3 cycles), fix stale assertions and broken refs only; STOP on real regressions
4. **Rebuild indexes** — unconditional CocoIndex + Graphify (we know the codebase is clean)

**Implicit mode** (called by review-implementation Phase 0): Git diff delta — only touch what changed:
1. **git diff** — detect changed files vs merge-base
2. **Delta structural update** — update only structural test refs related to changed files (not full scan)
3. **Run full test suite** — confirm nothing broke
4. **Conditional rebuild** — rebuild indexes only if relevant source files changed; skip if only docs/lockfiles changed
