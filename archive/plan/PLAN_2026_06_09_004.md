# PLAN_2026_06_09_004

## Problem Statement

Graphify's AST extraction creates nodes per unique import path string, not per canonical file path. This produces duplicate "ghost" nodes when the same file is imported via different relative paths (e.g., `App.tsx`, `src/App.tsx`, `frontend/src/App.tsx`). The current dedup script at `utility/dedup_graph_nodes.py` only handles suffix matching (Phase 1), missing:
- Moved/renamed files whose paths no longer resolve
- Files whose import path omitted a directory prefix
- True extraction duplicates (same file, same label, same location → two node entries)

## Goals & Non-Goals

### Goals
- Catch ALL real duplicate ghost nodes in a single run of the dedup script
- Script is idempotent (running twice produces same result)
- No false positives (never merge nodes that represent different content)

### Non-Goals
- Fixing graphify's upstream AST extraction logic
- Modifying git hooks or CI/CD pipeline
- Merging section-level nodes that share labels but differ in location (e.g., 39 "Functions" sections in ARCHITECTURE.md)

## Success Metrics

0 file-level ghost nodes remain after one run. All 207 current ghosts either merged or confirmed as unresolvable references to genuinely deleted files.

## Technical Approach

Add three new matching phases to `utility/dedup_graph_nodes.py`:

### Phase 2 — Basename Uniqueness Match
For each ghost node, check if any canonical file shares the same basename. If exactly one canonical file has that basename, the ghost is a duplicate of that canonical file.

Catches: moved/renamed files with unique filenames (session files, plan files).

### Phase 3 — Parent-Prefix Match
For each ghost source_file S, try prefixing S with the parent directory of each canonical path C. If `{parent_dir}/{S}` exists on disk, it's a match.

Catches: files referenced without their full directory prefix (e.g., `routes.py` → `app/routes.py`).

### Phase 4 — True Duplicate Merge
Within the same canonical file, merge nodes that share identical label AND source_location. These are AST extraction artifacts where the same logical node was emitted twice.

Catches: cases like `AGENTS.md` having 2 nodes with `label=AGENTS.md`, `source_location=L1`.

## Implementation Plan

### Files to Create, Modify, or Remove
- **Modify:** `utility/dedup_graph_nodes.py` — add Phases 2, 3, 4

### Architecture & Design Decisions
Matching is conservative: skip ambiguous cases (multiple candidates) rather than risk false merges. Ghost nodes that can't be matched to any canonical file are left as-is (they reference genuinely deleted files).
